# grvsnh.dev

Personal portfolio website inspired by a physical filing cabinet & drawer.

Built with **React 19**, **Vite**, **Tailwind CSS**, **Motion**, and **TypeScript**.

## Features

- **Drawer-Inspired Portfolio**: Interactive 3D/animated cabinet drawer UI with pull-out document files.
- **Project Showcase**: Visual cards for AI, Web Graphics, and Full-Stack projects.
- **Experience & Education**: Structured file tabs for career history, academic background, and skills.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
